# Extended Einsum site

This Astro/Starlight site is published at <https://extended.einsum.org> by the
`extended-einsum` Cloudflare Pages project.

- Build command: `npm run extended:build`
- Build output: `extended/dist`
- Production branch: `main`
- Watched paths: `extended/*`, `package.json`, and `package-lock.json`

Run `npm run extended:dev` from the repository root for local development.
